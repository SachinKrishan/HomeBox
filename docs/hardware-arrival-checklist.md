# Hardware arrival checklist

Run this checklist on each M900 while it is still inside the seller's return window.

## Physical inspection

- Photograph the unit, serial label, power adapter, and shipping condition.
- Confirm the adapter wattage and connector fit.
- Check case, USB ports, Ethernet port, display output, fan, and power button.
- Open the case and record RAM, system SSD, Wi-Fi card, caddies, and cables.

## Firmware and diagnostics

- Enter BIOS/UEFI and record its version.
- Confirm CPU, memory, storage, and network adapter are detected.
- Run the built-in diagnostics if available.
- Run a memory test and inspect SSD SMART health.
- Stress CPU and monitor temperature, fan noise, throttling, and shutdowns.
- Test every intended Ethernet and USB port.

## Acceptance

- No unexplained crashes or thermal shutdowns.
- No SMART failure indicators.
- Stable wired network connection.
- Both machines can boot from a USB installer.
- Missing or faulty parts are documented before the return deadline.
